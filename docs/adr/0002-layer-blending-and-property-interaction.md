# ADR 0002：图层混合与拖动属性控件

- 状态：已采用
- 日期：2026-10-07

## 决策

1. `LayerRecord` 保存 `opacity` 和字符串枚举 `blendMode`。旧工程缺少混合模式时按正常模式读取。白色背景、绘画图层和文件夹都支持这两个属性。
2. 首批模式为正常、正片叠底、滤色、叠加、变暗、变亮、柔光、强光、差值、添加（发光）。以预乘 RGBA 的 source-over 公式处理源和目标各自的透明度。
3. 全部图层使用正常模式和 100% 不透明度时保留原来的直接渲染路径。需要混合时先在透明的视口纹理中合成，之后才叠加到透明棋盘上，棋盘不会参与混合计算。显示、取色、缩略图和导出共用合成逻辑。
4. 文件夹采用隔离合成：先合成子树，再把文件夹的混合模式与不透明度应用到整体。临时纹理按嵌套深度复用，原始绘画数据仍保存在稀疏 GPU 图块中。暂不提供穿透模式。
5. 支持光栅顺序组的 GPU 使用 tile-memory programmable blending；其他 GPU 在每层开始前通过 GPU blit 获取不可变背景纹理。两条路径共用混合公式，均不将画布像素回读至 CPU。
6. `VerticalDragProperty` 是可复用的轻量 UIKit 控件。数值模式向上拖动增加、向下减少；选择模式在垂直拖动时展示自定义列表，松手提交，取消则恢复。图层不透明度拖动 200 pt 对应完整的 0–100% 范围。
7. 一次属性拖动是一个编辑事务：过程仅预览，结束后通过现有 `replaceLayerStack` 命令提交一条历史。多选时作用于全部选中图层；操作未选中的属性时仅作用于该图层。保存、撤销和页面切换前结束事务，取消手势不生成历史。

## 验证

- iPadOS 通用目标构建。
- Mac GPU 实际编译 shader，并检查十种模式的 90 组预乘 RGBA 结果。
- 使用实际合成函数验证文件夹整体不透明度、嵌套、同级临时纹理复用、隐藏和正片叠底，覆盖两条 GPU 路径。
- 验证旧版图层元数据兼容及新属性编码往返。

## 网点效果与滑出按钮（2026-10-07）

- 图层增加可选的 `LayerToneEffect`，缺省表示没有网点效果。保存启用状态、线数（线/英寸）、角度、浓度；关闭效果保留参数。初始参数为 60 线/英寸、45°、50%。
- 网点是合成 shader 的源颜色变换：原始亮度、像素 alpha 与浓度决定黑色圆点覆盖率，点外透明；原始图块不变。线数通过页面 DPI 换算为画布像素周期。文件夹先合成子树，再作用网点效果及混合属性。
- 网点锚定画布坐标，抗锯齿宽度根据缩放解析计算，避免奇数像素平移导致导数采样变化。低缩放时显示平均覆盖率以抑制摩尔纹。显示与导出共用效果代码。
- 可复用的 `SlideOutButton` 用 UIControl 追踪完整按下、移动、松开过程：在按钮内松手执行普通动作，在按钮下方松手展开附属参数，其他方向移出或取消不执行动作。底部短横线标记滑出能力，参数展开时高亮；无障碍动作也可展开参数。
- 网点参数区属于 UI 状态，位于图层控件与列表之间。展开／收起不改变效果启用状态。参数复用数值拖动控件及单次历史事务。
- 已在 GPU 上覆盖两条合成路径，检查网点浓度、线数、角度、透明度、文件夹效果、关闭效果、平移／旋转锚定及元数据往返。
