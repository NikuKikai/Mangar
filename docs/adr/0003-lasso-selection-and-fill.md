# ADR 0003: 套索选区与填充

- 状态：采用
- 日期：2026-10-08

## 方案

- 矩形和套索选区共用修饰键入口：无修饰键替换，Shift 加算，Option/Alt 减算，Shift＋Option 交集。触笔开始时确定运算方式。
- 路径记录画布坐标，自动闭合，按奇偶规则处理凹形和自交。GPU 将三角扇逐样本反转 stencil，再通过 MSAA resolve 生成分块 R8 灰度遮罩；CPU 只整理几何与分块范围，不栅格化像素。
- 已提交选区继续使用原有稀疏纹理、GPU bounding box reduction、灰度合并操作与像素边沿蚂蚁线。选区不是持久化的多边形对象，路径只属于可重放命令。
- 手势期间以独立 GPU 折线路径预览，不修改已提交的选区或图层像素；合并同一事件中的 coalesced samples 后更新预览缓冲区，动画帧复用该缓冲区。取消丢弃路径，松笔只提交一次历史。
- 套索填充使用开始时的主绘画图层、颜色与不透明度，并乘以当前选区遮罩，执行 premultiplied source-over。GPU 同时归约实际填充区域，未覆盖的区块不发布、不标脏；操作通过独立命令进入历史并重放。
- 手指可操作选区工具，套索填充与画笔一样仅由 Pencil 执行。选区手势中加入第二根手指会取消预览并切换视口操作；Pencil 操作期间不触发双指/三指历史快捷手势。

## 验证

构建通过后，以同一 shader 与栅格化实现运行 GPU 检查：凹形、自交、MSAA 灰度边缘、区块接缝、选区四种合并方式、半透明填充的选区限制与脏区归约。
