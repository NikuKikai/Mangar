# ADR 0004: 单通道图层蒙版

- 状态：采用
- 日期：2026-10-08

## 方案

- 图层用 `hasMask` 表示是否拥有蒙版，支持绘画图层、文件夹及程序化背景。蒙版范围为画布，未分配区块隐式为白色，创建时无需铺满纹理。
- `TileKey.target` 区分内容与蒙版；内容沿用 RGBA8，蒙版采用 R8。两者共用分块、脏区、快照、增量保存与历史重建路径，GPU 纹理和解压数据分别为每像素 4 字节及 1 字节。
- 主图层与编辑目标分别维护。点击内容或蒙版缩略图切换目标；图层多选依旧保留主对象，绘画只修改主对象的当前目标。新建图层、切换页面或目标失效时回到内容。
- 笔画命令与套索填充命令捕获编辑目标。编辑蒙版时，颜色按 `0.2126 R + 0.7152 G + 0.0722 B` 转为灰度，原应用颜色保持不变。灰度按笔刷覆盖率与不透明度混合写入；默认不积累笔刷使用独立覆盖率预览，橡皮擦恢复白色。
- 蒙版绘画受选区及图层/祖先锁控制。预览不覆盖已提交纹理，提交发布新 R8 纹理，因此撤销与重放不会依赖当前 UI 目标或颜色。
- 合成时先将稀疏蒙版绘制到当前视口的 R8 临时纹理，再将其值乘到内容的预乘颜色和 alpha 上。网点效果先作用于内容，蒙版随后调制透明度；文件夹在子树隔离合成后应用蒙版。显示、取色、项目缩略图和 PNG 导出共用此路径，兼容 ROG 与 backdrop 两种合成实现。
- 蒙版缩略图显示全画布的灰度预览，位于原缩略图右侧，以边框表示当前编辑目标。
- 删除按钮根据当前缩略图目标执行操作：选中蒙版时只删除主对象的蒙版，回到内容目标。删除同步清理 R8 图块及缓存，以保证重新添加为全白；命令历史仍可重建删除前的蒙版。
- 图层动作区分为两行，第二行放网点与蓝色检查开关。蓝色检查是临时视口状态，隔离显示当前缩略图：内容使用原始 alpha（文件夹使用子树合成 alpha），蒙版以灰度值作为 alpha；固定蓝色按 alpha 预乘。检查目标本身的隐藏、透明度、混合模式、网点与蒙版不参与检查，文件夹内部仍正常合成。可在检查时描绘，选区与页面参考框仍显示；取色、缩略图及导出走正常合成，不受检查影响。
- 页面状态版本提升至 3，读取兼容版本 2；原内容图块名称不变，蒙版图块使用独立名称。LZFSE 容器已有解压长度字段，扩展为只接受规定的两种长度，并按目标再次校验。原子 `state.json` 提交同时关联内容与蒙版，合并/拆分按照通道数裁切、平移，蒙版补白。

## 验证

- 实际 GPU 路径：单通道预览与提交、覆盖率/不透明度、橡皮擦、选区裁切、快照重放、套索填充、脏区归约，以及缩放旋转下的对齐。
- 合成检查覆盖绘画图层、背景、文件夹、嵌套/连续蒙版及 ROG/fallback 两条路径。
- 存储检查覆盖 R8 LZFSE 往返、增量提交、重新打开、旧版本兼容，以及页面合并/拆分后的数值和坐标。

- 蓝色检查验证覆盖半透明内容、R8 alpha、隐藏目标、视口平移后画布外透明，以及删除清理和恢复，两条 GPU 合成路径均通过。

## 清空编辑目标

- Topbar 使用放射形短线图标。清空是捕获图层 ID 与内容/蒙版目标的独立命令，由当前历史节点的选区参与重放，支持撤销/重做，不依赖当前颜色或笔刷参数。
- 无选区时释放目标全部稀疏图块：内容回到透明，蒙版回到隐式白色，与橡皮擦语义一致。有选区时只处理现有且与选区相交的区块，通过 GPU 按覆盖率清除内容预乘 RGBA，或将蒙版混合至白色，并归约实际变动 bounding box。
- 保持原纹理不可变；重放同时恢复图块与选区。锁定目标禁止清空，程序化背景及文件夹的内容暂不支持清空，但其蒙版支持。
- GPU 验证覆盖选区内外与半覆盖率、原纹理不变、脏区、重放一致性、全清空释放稀疏图块，以及命令序列化；ROG 与 fallback 检查均通过。
