# ADR 0005：透明色与应用预设色

- 状态：采用
- 日期：2026-10-08

## 方案

- 左侧工具栏的当前颜色与半高透明色块互斥。透明色不可编辑，不覆盖当前 RGB 或笔刷参数；点按当前颜色退出透明模式，再次点按打开原颜色设置面板。
- 透明色以擦除语义执行：圆笔捕获橡皮擦命令，套索填充命令捕获 `erases`。内容按覆盖率擦除预乘 RGBA，蒙版恢复白色。选区、笔刷不透明度与历史重放均沿用原路径，编辑过程中切换颜色不会改变已开始操作。
- 当前色块向右滑出 UIKit 浮层；面板由一行操作区与 4×4 色格组成。拖动时高亮候选，释放在色格上应用并关闭，释放在存入按钮上进入存入模式并保持打开。存入模式点击色格替换预设，随后退出存入模式、保留面板。点击外部关闭且不拦截其他界面操作。
- 预设保存 RGB 与不透明度，不包含笔刷其他参数。16 色位及透明色选择存入应用 UserDefaults；不随工程保存或切换，读取时校验数量与取值范围。

## 验证

- 设备构建；实际 GPU 检查透明色套索对内容和 R8 蒙版的作用、选区裁切与原绘画功能。
- 独立 UserDefaults 检查 16 色位、替换及不透明度、跨实例读取、非法值拒绝，以及透明色选择不改写当前笔刷。
