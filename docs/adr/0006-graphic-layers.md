# ADR 0006：通用图形图层

- 状态：采用
- 日期：2026-10-08

背景的常量颜色表示由 [ADR 0014](0014-unrestricted-canvas.md) 扩展为 `solidColor`；本记录保留通用图形类型的设计。

## 方案

- 图层类型改为 `paint / folder / shape`，替代背景专用的 `solidWhite`。图形层持有 `LayerShape`；初始实现提供 `rect(bounds, fill)`，填充颜色为 RGBA，其他几何形状以后扩展。
- 新项目的背景是一张默认上锁的图形层，内容为明确覆盖初始画布范围的白色 Rect。几何数据无需栅格图块，仍通过 GPU 渲染；混合模式、不透明度、网点及 R8 蒙版沿用现有合成。
- 图形层内容暂不提供创建、编辑或栅格绘画入口；蒙版仍可编辑。缩略图的小图标标识为图形层。
- 页面合并/拆分裁切和偏移矩形范围，保留填充颜色。矩形具有明确范围，不再以缺省范围表示全画布。
- 旧 `solidWhite` 在读取时映射为图形层：有 `paperBounds` 时保留原范围，否则由所属页面补齐全画布矩形。保留图层 ID、层级及其他属性。新编码不再输出旧类型或旧字段。
- 页面状态格式提升为 4，读取兼容 2、3；既有图块引用、压缩及原子提交机制保持一致。

## 验证

- GPU 检查覆盖矩形范围、填充 alpha/颜色、图层透明度、蒙版、蓝色检查，以及 ROG/fallback 两条合成路径。
- 数据检查覆盖旧全画布/局部背景迁移、新编码无旧字段、页面状态兼容、白色 Rect 初始化、合并拆分范围与原图块保存逻辑。
