# ADR 0007：可重放的 GPU 笔刷系统第一版

- 状态：采用
- 日期：2026-10-08

## 背景与范围

替换原圆笔实现，不兼容旧笔刷设置。已有工程的栅格图块无需转换。第一版提供铅笔、G 笔、持续出墨的针管笔、二值笔，继续支持橡皮擦、透明色、R8 蒙版、分数选区与命令历史。纹理素材、双重笔尖、混色、丝带笔触和稳定器留待后续。

CSP/Photoshop 的内部 GPU、线程和存储架构没有公开可验证的完整实现，本方案不将产品行为推断为其源码事实。依据公开文档的笔尖间距、动态、流量与笔画不透明度区别，并参考开放引擎的定义/运行状态分离。

## 模块边界

- `Brushes/Model`：可编码的配置、笔刷定义、输入样本。定义不持有 Metal 资源或 UI 状态。
- `Brushes/Presets`：漫画笔刷的参数化定义；未来素材笔尖在定义/编译层扩展。
- `Brushes/Runtime`：GPU 资源、增量输入、笔画事务、提交/取消及持续输入时钟。
- `Brushes/GPU`：落点生成、16×16 子块索引、覆盖率累积与着色内核。
- `Brushes/UI`：现有浮动参数面板的最小接入。应用设置继续由 AppToolPreferences 管理。
- 编辑器只录制命令和调度事务；文档渲染器负责图层合成，不再实现笔刷采样。

## 输入与确定性

每个样本记录画布坐标、经过全局压感曲线的压力、相对时间、倾角与方位角。输入与 GPU 落点不是一一对应：CPU 将输入段划为有上限的微段，GPU 维护距离/时间相位并插入落点、求局部动态。停笔出墨使用真实时间样本，随命令一起录制。随机数按种子、落点序号和参数通道生成，与 GPU 提交批次无关。

命令冻结配置、完整解析后的定义及版本、随机种子、编辑对象和样本；选区按历史顺序重放。笔画的 UUID 区分活动预览与重放。绘画过程中 UI 修改设置不改变已开始的笔画。

## GPU 执行与事务

沿用 256×256 文档图块。GPU 顺序生成增量落点，再为每个 16×16 子块建立有序索引；像素内核只访问对应子块落点，不扫描整条笔画。CPU 只计算保守候选范围/分发，不计算实际笔尖或累积颜色。

活动笔画保留不可修改的原始图块、独立输出及 R16Float 双缓冲覆盖率。落点、粒子随机、压力/倾角动态、抗锯齿、铅笔纸纹与最终混合均由 shader 执行。最终图块沿用 RGBA8，蒙版 R8。保守 dirty bounding box 用于即时调度，GPU 原子归约维护实际受影响像素 bounding box；图层内容范围继续使用 GPU 归约。

预览与真实数据分离：预览仅替换渲染输入，抬笔直接提升同一事务结果，取消丢弃工作集。历史重放调用相同执行器。所有 GPU 工作与合成在同一个 command queue 上有序执行；热路径不 `waitUntilCompleted`。只在 CPU 读回/保存时同步。中间资源由 command buffer 保活，落点批容量有严格上限，不可截断长笔画。

## 累积语义

- `flat`：同笔画取最大覆盖率，最后应用笔画不透明度；G 笔默认，避免重复经过加深。
- `flow`：按流量累积覆盖率，最后应用笔画不透明度；铅笔与针管笔默认。
- `buildUp`：每个落点包含不透明度参与累积，用于需要持续叠加的预设。
- 选区在最终合成时乘一次，避免同一笔画将分数选区反复叠满。蒙版以选中颜色的亮度作为目标值，擦除恢复白色。

## 第一版预设

| 预设 | 行为 |
| --- | --- |
| 铅笔 | 压力调尺寸/流量、倾斜椭圆笔尖、固定于画布的程序化纸纹、流量累积 |
| G 笔 | 强压力尺寸响应、硬边抗锯齿、flat 累积 |
| 针管笔 | 尺寸不依赖压力、按距离和时间出墨、停留时有上限地扩墨、flow 累积 |
| 二值笔 | 硬阈值无抗锯齿，默认全不透明，flat 累积；分数选区/笔画不透明度仍可产生半透明 |

持久化当前预设与参数、颜色；不随项目改变。切换预设应用其默认笔刷参数，保留颜色与笔画不透明度。后续可扩展每个预设独立保存的自定义参数。

## 取舍与后续

第一版使用内建程序化笔尖，尚未提供素材资源加载器。GPU 生成器串行维护一条活动笔画的相位，栅格化并行；后续性能证据需要时再扩展分段 prefix scan。极大笔刷和短时间大量输入仍可能增加 GPU 排队，需要实机持续观察，不能声称所有旧设备无限性能。长历史及工程不保存笔刷操作日志，仍沿用现有有限内存历史和栅格工程保存。

## 验证要求

实际 Metal 内核检查四种笔刷、压力/时间/倾角、确定性分批重放、平涂/流量、二值边缘、跨图块、选区/蒙版/擦除、预览提交与取消；构建后安装并重启连接的 iPad。实机手感由用户继续确认。

## 2026-10-08 修订：参数记忆与不透明墨水

用户试用指出切换预设丢失设置、针管笔高速不变细，以及出墨量被误实现为透明度。采用以下修订，替代上面的预设切换和墨水 flow 累积方案：

- 每个预设独立持久化尺寸、不透明度、出墨量/流量、间距、随机参数和累积设置；另存当前预设，RGB 颜色全局共享。重复点击当前预设不会复位。配置库使用 `Mangar.tools.brushLibrary.v3`，读取并保留此前 v2 当前笔刷设置。
- 定义层增加 `deposition = pigment / solidInk`，避免把供墨量和覆盖率流量混为一谈。铅笔继续支持颜料浓淡累积。G 笔、针管笔、二值笔使用不透明墨水；供墨量和供墨抖动改变尺寸而不改变内部墨色。同笔取最大几何覆盖率，边沿抗锯齿也不因停留反复加深。只有用户明确调低整笔不透明度、选区覆盖率或图层不透明度等，才产生相应透明效果。
- 针管笔按样本时间求速度，以笔尖直径/秒归一化，25ms 时间常数平滑后，按反比关系缩小尺寸：`scale = clamp(sqrt(amount / (1 + speed / 40)), 0.15, 1)`。G 笔仅用出墨量改变尺寸，保留压力尺寸响应。停留扩墨保留有上限的模型。这是本应用的可调近似，不声称复刻专有算法，也不声称所有真实针管笔具有相同速度响应。
- 间距同时参考减小后的尺寸，防止高速/少量出墨变成断开的圆点。GPU 继续维护速度和随机状态，分批和整笔重放须逐像素一致。
- 参数面板对墨水笔显示“出墨量”和“出墨抖动”，不显示颜料累积模式按钮。笔尖圈异步读取 GPU 的最后实际半径，跟随速度/出墨量/停留扩墨，无主线程等待。
- 参考 [CSP 官方尺寸速度动态、密度与整笔不透明度说明](https://tips.clip-studio.com/en-us/articles/563)、[Krita Flow/Opacity](https://docs.krita.org/en/reference_manual/brushes/brush_settings/opacity_and_flow.html) 和 [Photoshop 绘画工具](https://helpx.adobe.com/photoshop/using/painting-tools.html)。这些软件的覆盖率 Flow 可用于颜料引擎；本应用按漫画墨水需求另外定义供墨行为。
- 验证增加：各预设参数切换/重复选择/重载/旧配置迁移，共享颜色，以及低供墨仍为原 RGB/全不透明、速度变细、连续实线和确定性重放。

## 2026-10-08 修订：倾斜尺寸与工具分组

- 铅笔新增 `tiltSize` 尺寸动态：`diameter *= 1 + tiltSize * (1 - sin(altitude))`。直立时为原尺寸，放平时增大；默认强度 1.25。椭圆伸长作为独立形状动态保留，强度调整为 0.65。间距、候选 bounding box 和实际笔尖圈均纳入尺寸变化。其他笔的 `tiltSize = 0`。
- 参数面板删除笔刷预设 tab，仅显示当前工具名称与参数。左侧工具栏分成独立铅笔按钮和墨水笔组按钮。墨水笔按钮单击使用上次的笔，向右拖出展开紧凑工具列表，在行上释放立即选中并收起；在列表外释放则取消。图标反映当前记忆的工具，并以右侧短竖线提示滑出方向。无动画，无系统弹出菜单，弹出区域不覆盖其余画布的输入。
- 墨水笔组记忆 G 笔/针管笔/二值笔的最后选择，切换到铅笔或其他工具不覆盖它，并按应用持久化。各预设参数仍独立。键盘 P 选铅笔，B 选记忆的墨水笔，E 选橡皮擦。
- `UI/SlideSelectToolControl` 是不依赖笔刷模型的通用右滑释放选择控件，供其他工具组复用；禁用、失活、移除或手势取消时清理浮层。
- GPU 检查补充铅笔倾斜时两个轴的尺寸增长、其他笔不受影响，以及工具组最后选择的持久化。

## 2026-10-08 修订：可编辑参数响应曲线

- 笔刷定义升级为 v4。大小、流量/供墨量、不透明度各自拥有压力、速度、倾斜三条曲线；每条曲线独立启用，最终参数为基础值乘以所有开启曲线的取值，关闭时因子为 1。移除旧的隐式尺寸/压力流量公式，预设行为迁入曲线默认值。倾斜椭圆形状与停留扩墨仍是显式、独立的笔尖设置。
- 每条曲线保存五个等距输入控制点，使用无区间过冲的平滑分段三次 Hermite 插值，支持递减与非单调曲线。大小输出范围 0～3，流量与不透明度为 0～1。压力输入经过全局压感校准；速度以基础笔尖直径/秒计，经 25ms 平滑后用 `v / (v + 40)` 映射至 0～1；倾斜输入为 `1 - sin(altitude)`。
- 曲线与笔尖设置属于每个预设的应用级持久化配置。新增字段使用可选解码，旧配置未提供时解析为预设默认值。命令冻结完整配置和定义，曲线在笔画开始时编译一次，GPU 使用九条曲线的固定布局缓冲执行；调度范围包含尺寸曲线的最大倍数。
- 累积覆盖率现在包含落点的不透明度，取代上文“最后应用笔画不透明度”的实现描述：flat/不透明墨水取最大覆盖率；buildUp 逐落点联合累积；颜料 flow 逐步接近当前落点的不透明度上限，并保留此前更高的覆盖率。选区仍只在最终合成时乘一次。供墨量继续改变墨水宽度，不将墨水稀释成灰色。
- 参数面板新增与 topbar 同绑定的大小行；尺寸、不透明度、流量行末按钮打开独立动态曲线面板，任一来源启用则按钮高亮。曲线面板分来源 tab，可拖动控制点、独立开关和恢复预设。参数主面板覆盖间距、随机量、硬度、纸纹、倾斜形状、持续出墨、停留扩墨及适用的累积模式，使用统一左标签与右控件布局。通用 slider 缩减轨道及白色光标高度，禁用动画。
- 验证覆盖九种参数/输入组合、开关、三来源乘积、零尺寸、放大后的跨块边界、动态不透明度、平滑曲线无过冲、带动态曲线的分批确定性重放，以及曲线/笔尖参数持久化。

## 2026-10-09 修订：着墨行为全面参数化

- 定义升级为 v5，加入可持久化 `BrushRenderingSettings`：着墨方式（颜料/不透明墨水）、笔尖二值化、累积方式（平涂/流量/叠加）。三个设置不依赖预设名称；定义在笔画开始时冻结着墨方式与二值化，GPU 累积模式来自冻结配置。
- 参数面板为所有笔刷显示着墨方式、二值化和累积模式。二值化开启时硬度不参与计算，硬度行置灰；纸纹保留独立可调，它可让二值几何边缘内部产生浓淡。二值化指笔尖几何边缘，不把选区、整笔不透明度或纸纹强制为二值。
- 不透明墨水的出墨量仍改变笔尖尺寸，内部密度为 1。默认平涂维持既有行为；选择流量模式时覆盖率趋近当前不透明度，选择叠加时可随重复落点加深。显式选择其他累积模式属于用户控制，不改变默认墨水表现。
- 旧配置缺少 rendering 时，按旧预设与累积字段解析为原来的有效设置（墨水为平涂），编辑后完整存入 rendering。旧 accumulation 字段仅用于兼容读取。
- 实际 Metal 测试覆盖全部着墨方式 × 二值开关 × 累积模式，并验证四种预设在相同显式配置下逐像素一致、墨水累积可调和新设置的切换/重载持久化。
