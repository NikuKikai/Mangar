# ADR 0008：笔尖素材与独立笔刷资源

- 日期：2026-10-09
- 状态：已实施

## 决策

笔刷预设仅提供初始值。新增稳定 ID 的自定义笔刷资源，定义和当前 RGB 分离；复制时保存初始配方用于恢复默认，重命名不改变 ID。定义修订由规范化配方的内容散列标识，旧修订不可覆盖。资源放在应用 Application Support 的 BrushResources 目录，素材和定义分开存储。

图片导入使用透明度，或灰度（黑色着墨）乘透明度生成单通道 R8 覆盖率。最长边限制为 1024，单笔最多 16 张，保留比例；拒绝空素材。素材文件由两个 little-endian UInt32 尺寸和原始 R8 数据构成，不使用 base64；素材用尺寸和原始 R8 数据的 SHA-256 标识，按内容去重、不可变。导入不执行任何绘画栅格化。

每条笔画冻结完整解析配置、资源修订及素材快照；Data 使用值语义共享底层存储。历史重放不再查找可变资源。活动笔画中修改笔刷或重命名不会影响现有笔画，素材不随项目保存，项目继续保存最终栅格。

GPU 编译器将素材居中装入等尺寸 R8 纹理数组。GPU 选取顺序/种子随机素材，执行方向旋转、宽高比、纹理采样和覆盖率累积。图片笔尖替代程序化圆尖；硬度仅作用于程序化圆尖，纸纹仍独立。笔尖角度支持固定、运笔方向及笔倾方位；运笔方向在静止时沿用最后方向，首落点使用固定偏角。分块候选和子块索引包含旋转后矩形的保守外接范围。

参数面板提供比例、角度与方向模式，独立资源面板管理笔刷及笔尖素材。维持紧凑样式、即时更新和画布穿透；不在本阶段实现图片纸纹。

## 验证

生产 Metal 测试验证图片覆盖率、比例/旋转、方向跟随、顺序与随机多素材、跨块和确定性分批重放。资源测试验证复制/重命名/恢复、颜色隔离、修订不可变、重新加载与历史素材冻结。完成后构建、安装并重启 iPad。

## 实现补充

资源编辑自动保存；参数拖动期间合并 350ms 内的修改，切换笔刷、关闭资源面板与应用失活时立即落盘。应用工具设置独立保存当前自定义资源及颜色，旧预设参数保持可读。缺少或损坏的素材拒绝开笔，不静默退回圆尖。资源修订先写入不可变文件再原子替换目录清单，未引用的旧修订暂保留，不在本阶段做垃圾回收。

纹理数组带透明边沿与 mipmap，GPU 纹理缓存限制约 32MiB（单个活动数组可保留），CPU 素材缓存最多 32 个；命令快照仍由有限历史保活。素材和修订共享引用，而非每条笔画重新从磁盘读取。图片笔尖二值化对采样覆盖率使用 0.5 阈值。

资源面板可从参数面板标题行打开；内置笔刷和副本共用紧凑列表。副本默认值是复制时配方，内置笔刷默认值是出厂配方。素材缩略图可移除或向前重排，「圆尖」清空素材引用。自定义笔刷加入右滑工具列表；较长列表可滚动，滑出选择时边缘移动可滚动列表。

## 2026-10-09 修订：参数与笔刷管理分离

移除参数面板下的笔刷资源独立窗口和笔刷库、复制、重命名、恢复默认等管理入口。笔尖素材属于当前笔刷参数，导入通道、导入按钮、素材缩略图及移除/重排控件直接嵌入第一级参数面板。资源存储、稳定 ID 与冻结历史的数据结构保留，笔刷管理界面另行设计。本次不新建替代的管理入口。

## 2026-10-09 修订：内置油画笔尖

新增独立右滑展开的油画笔工具组，目前只有「平头油画笔」。默认直径 60、流量 0.7、间距 0.08，压力控制尺寸和流量，使用颜料 flow 累积与运笔方向旋转。预设仍仅是参数初值，不增加专用油画执行分支。

内置笔尖从 David Revoy 的 CC0 Deevad 25.01 包中提取 `chisel_streaks.png`，PNG 保持原样随 App 打包。按灰度黑色着墨解析成 R8，并核对固定内容 ID；与用户导入素材共用缓存、纹理数组及历史快照。内置素材从 bundle 解析，不依赖 App Support 中可变文件。保留来源、许可和下载校验和记录，未引入上游笔刷引擎或混色功能。
