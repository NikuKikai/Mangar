# ADR 0011：选区覆盖率观察、闭合填充与图层曲线

- 日期：2026-10-14
- 状态：已实施

## 选区观察

画布 topbar 的动态工具属性左侧设独立选区区块，存在选区时显示覆盖率观察开关、反转、清除及区块分隔线。观察模式在透明格子背景上独立显示蓝色选区，读取原始 R8 选区值直接作为 alpha，避免原画颜色影响观察；开关关闭时恢复原有像素边沿蚂蚁线。仅渲染可见图块，包含默认覆盖值和局部覆写，保留分数值；显示状态不写入绘画、历史或导出。

## 油漆桶

独立工具，使用应用级持久化容差与闭合间隙（画布像素，0–32）。第一版参考当前编辑图层原始栅格或蒙版；不参考其他图层、图层效果或着色预览。未分配绘画图块为透明、蒙版图块为白色。

离散连通性采用后台 CPU 扫描线算法，输入为当前目标的不可变稀疏 GPU 图块读回及选区读回。这不是连续描绘热路径；像素合成仍在 GPU，复用套索填充的 R8 形状覆盖与选区读取、图块边界统计、dirty bounds 路径。计算期间保持 UI 响应，历史或页面变化后丢弃过期结果。

闭合通过可分离边界扩张阻断小缺口，然后只从冻结的连通内部恢复边界窄带。不会从扩张结果继续洪泛，避免重新漏出闭合缺口。0 覆盖选区是边界，分数选区允许连通且在 GPU 合成时仅乘一次。

命令记录紧凑扫描线区段、颜色、不透明度、目标和擦除标志，避免保存全画布位图，也避免重放时重新计算边界。写入仅分配命中图块；支持蒙版和透明色。第一版不包含跨图层参考与专门的抗锯齿边缘扩展。

## 图层曲线

非破坏性可开关图层效果，兼容普通图层、图形图层和文件夹。保存 RGB 总曲线及红绿蓝独立通道，每通道五个控制点，使用保形三次 Hermite 平滑插值。主曲线先执行，再执行单通道曲线。

以 R32Float 256×4 LUT 供 shader 线性采样。在非预乘 RGB 上调整，然后乘回原 alpha；不改变透明度、不为原透明区域生成颜色。曲线先于网点、图层蒙版、图层不透明度和图层混合执行；文件夹曲线作用于子项合成结果。原始着色观察绕过效果。预览、PNG 和页面缩略图共享图层 shader。

按钮紧邻网点按钮，点击开关效果，下滑释放打开参数区。两个效果的参数区共享位置且互斥，但两个效果本身可同时启用。曲线拖动实时预览，释放后以一次 replaceLayerStack 命令提交，支持撤销、多图层编辑；旧项目缺失 curves 字段时保持无效果。

## 验证

验证 GPU 曲线颜色/alpha、禁用和透明像素、序列化与旧图层兼容；填充闭合、过大间隙、恢复边界窄带、跨图块和残缺边缘图块、空/分数选区、默认蒙版及命令重放序列化。执行既有 Metal 笔刷回归与设备构建。
