# ADR 0012：中文、日文、英文界面本地化

- 日期：2026-10-14
- 状态：已实施

## 决策

支持简体中文（zh-Hans）、日文（ja）和英文（en）。跟随 iPad 系统／单个 App 语言设置，不再增加应用内语言选择器。英语为不支持的系统语言的默认回退。保留 Mangar 名称、快捷键、文件格式、枚举原始值、资源 ID 和单位。

翻译集中保存在 Localization/Localizable.xcstrings，中文为源语言，各语言手动维护。Foundation 的 L10n 包装统一服务 SwiftUI、UIKit、错误提示及生成名称；Bundle 决定当前语言。动态文本使用 %@ 占位符，百分号在格式模板中转义为 %%，参数始终作为字符串传入，不作为新的格式模板。

项目名、页名、图层名、自定义笔刷名是用户内容，不对现有数据做翻译、迁移或覆盖。新建时的默认名称按当前语言生成，之后作为普通文档数据保存。完整混合模式名称与紧凑图层徽章名称分开翻译，避免截断导致不同模式重名。固定宽度参数标签限制为单行，必要时轻微缩小文字，保持紧凑面板。

覆盖项目管理、新建、页面一览、编辑工具栏、笔刷及动态参数、图层效果、颜色、UIKit 菜单和辅助功能、错误消息。Apple 系统文件选择器、分享表单和系统错误详情由系统自身处理语言。

## 验证

Tests/Localization/check.py 检查所有翻译、格式占位符、静态代码引用及混合模式短名唯一性。run.sh 在编译后的实际 .app 内验证三种语言资源，以及百分比、用户名称和输出文件名插值。继续运行实际 Metal 功能检查与设备构建，确认本地化不改变文档或笔刷行为。

## 补充：应用内语言设定

根据后续用户要求，增加全屏应用设定页面及持久化语言选择（跟随系统、简体中文、日文、英文）。编辑菜单和项目管理右上角菜单均可进入。显式选择使用对应语言资源 Bundle；系统选项继续由系统／单个 App 语言决定。切换立即刷新 SwiftUI、UIKit 菜单与辅助说明，并为日期格式注入对应 Locale，不通过重建文档或编辑视图 identity 实现。当前工程、未保存绘画、视口和用户名称保持原样。设置页覆盖下暂停视口的显示刷新，返回后恢复。
