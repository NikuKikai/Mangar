# ADR 0013：真实内容边界、空块回收与反选规范化

- 日期：2026-10-15
- 状态：已实施

## 图块边界

内容 bounding box 与 dirty bounds 分开维护。GPU 在正式图块发布后异步扫描量化后的纹理，绘画内容以 alpha > 0 为占用，R8 蒙版以偏离默认白色为占用。覆盖笔画、选区清空、套索／油漆桶填充和恢复路径。实际内容范围可以在擦除后缩小，为空则删除正式 texture；删除保持 dirty，保存时通过完整存活键集合移除旧文件引用。

测量绑定纹理身份，过期结果不能删除后续版本的图块。连续描绘路径不等待测量；保存／快照／缩略图需要真实结果时同步已提交的 GPU 工作。缩略图复用维护的内容边界。恢复文档时重新测量，撤销不依赖已回收的当前纹理。

## 选区

图块继续保存实际覆盖值，不把局部纹理解释为补集。默认值为选中时，Shift 联集以填补例外区域的方式求值；矩形和 R8 套索使用同样的真实覆盖率规则。输入类型和默认值使用独立位标志，避免混淆。

GPU 分别测量正覆盖范围与偏离默认值的范围。仅全块等于默认值时移除覆写；默认 255 时全零图块是有意义的例外，必须保留。选区反转与双次反转、默认 255 的加减算均验证量化后覆盖值。

## 画布边缘蚂蚁线

低倍率时，边界像素小于一个屏幕像素，单纯在图块内部寻找相邻像素边沿可能被屏幕采样遗漏。边界图块增加 0.75 屏幕像素的外侧渲染余量，shader 在真实画布边界读取内侧选中值并绘制边沿。内部图块边沿仍以 > 0.5 / <= 0.5 的邻接关系判断，着色观察不增加余量。

## 验证

实际 Metal 检查反选后的矩形和分数 R8 套索加算、减算、双反转、默认值图块的保留／移除；检查内容 bounding box 缩小、最后像素回收、蒙版黑／白语义及过期测量；检查低倍率四边线、内部无额外线和空选区无边缘线。运行既有 GPU 回归及设备构建。
