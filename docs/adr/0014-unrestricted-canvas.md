# ADR 0014：统一稀疏画布与无限制项目

- 日期：2026-10-15
- 状态：已实施

## 已确认的产品约束

底层只有一种稀疏画布，有限页面只是具有固定轴边界。项目用途（书籍／无限制）与页面结构（书籍对开排列／普通多页卡片）独立存储。保留现有书籍新建、编辑和对开页交互及视觉；无限制项目在具体参数之前选择，X、Y 轴各自设置起始与终止：起始为负无穷或 0，终止为固定坐标值或正无穷。允许负无穷到固定值的半无限范围。普通卡片支持增加、删除、重排、打开页面，不提供对开合并拆分。以后可增加折页结构，此次不实现。

默认背景使用 solidColor 图层，白色、锁定，表示常量颜色而非分配纹理。shape 类型保留，不新增形状工具。无限制项目禁用油漆桶。此次不实现尺寸修改，不增加工程迁移流程。

## 统一核心

CanvasBoundary 的 width／height 保存可选上端点（nil 为正无穷），startsAtZeroX／Y 保存下端点为 0 或负无穷的标记；完全有限轴范围为 [0, value)。内容范围、固定边界、视口分别管理。64 位有符号图块坐标用向下取整划分，块内索引非负。CPU 世界坐标为 Double，GPU 采用按图块对齐的邻近原点；笔画微批重定位保持间距、随机序列、湿笔颜料状态，渲染从视口附近原点计算相对位置。纹理始终 256×256。

正式内容 bounding box 扫描完整图块，不依据有限页面裁掉有效存储。图层与页面范围由实际图块联合获得；默认 solid color 不扩大内容范围。有限边界限制写入和显示，而不是分配完整位图。无边界空项目采用固定初始观察范围；缩略图／导出始终解析出有限范围。

## 选区

全局反转标记＋局部空／全满标记／混合值纹理。全零省略，全 255 不保存独立 texture。读取应用反转，编辑实际覆盖率后再编码；反转不复制整张选区。绘画、填充、拾色共享取样接口。边界裁切以独立条件处理，不创建边界 mask。选区超过视口时，在视口边缘补显示裁切蚂蚁线，显示行为不修改选区。

## 缓存与多级显示

统一预算驱动缓存，而非按项目用途判断。普通书籍图块数量低于预算时保持原路径；大型有限页面也触发缓存。GPU 非可见块可转存无损压缩的临时后备文件，保留键、内容框与纹理修订，需编辑／显示时恢复；未保存内容不可丢失。保存／历史快照覆盖后备块。按可见范围查询并合成，低倍率以分级图块显示，缓存与修改版本关联，失效后重建。

## 文件与历史

每页仍独立保存，项目关联页面 ID。记录有符号坐标、边界和内容范围；固定轴允许较大值而不分配巨大 texture。命令保留世界坐标和完整参数，撤销重放不依赖当前驻留图块。保存原图块并继续 LZFSE、增量且原子发布。导出为有限矩形，大尺寸输出须检查设备可用范围，不能尝试生成无限图像。

## 验证要求

生产 GPU 检查负坐标、跨原点、远坐标、有限轴裁切、笔画分批确定性与湿笔拾色。检查选区标记与反转、视口边缘线、solid color 和普通页面结构。验证缓存换出／恢复不丢失像素，保存和撤销覆盖后备块，多级图块与原图一致。最终执行设备构建、安装与重启，并保持三语设置。

## 本次实现

- `Editor/CanvasBoundary.swift`：统一轴边界、独立的 `ProjectPurpose` / `PageStructure` 和新建请求。新建画面先选择书籍或无限制；无限制默认 X 轴 [0, 2048)、Y 轴双向无限；可分别修改起始、终止。普通卡片支持多页、重排和删除。
- `Rendering/CanvasTileIndex.swift`：按已分配图块建立稀疏坐标索引，在视口单元和已分配键之间选择较小的查询范围。
- `Storage/CanvasTileArchive.swift`：拥有独立文件引用的 LZFSE 后备存储与历史快照。同卷优先使用硬链接共享不可变文件，失败时复制；原工程清理旧文件不会破坏快照。保存的页面索引同时记录实际内容框，打开页面不解压全部像素。
- `Rendering/CanvasTileLOD.swift`：GPU 将四个子图块平均到父图块。负坐标采用算术右移划分祖先；内容缺省透明、蒙版缺省白色。修改后失效重建。
- 原始图块驻留预算 128 MiB，多级纹理缓存预算 64 MiB；当前可见图块和活动笔画受保护。因此驻留预算是软预算，活动笔画、帧缓冲和文件索引不计入这两个数值。换出失败时保留原数据并报告错误，禁止把读取失败当作有效空图块保存。
- 选区以全局反转位和常量图块标记保存；矩形完全覆盖的图块直接更新标记。混合图块在读取时由 GPU 生成临时反转缓存。连续值观察与视口裁切线使用 R8 视口缓存，内部蚂蚁线仍读取原图块及四邻块、以大于 0.5 为判定，在真实像素边沿显示；不遍历无数据的巨大世界范围。
- 背景使用锁定的白色 `solidColor` 图层，无像素图块。`shape` 保留。对开合并、拆分仍可通过 `solidBounds` 保留各半页的白色覆盖范围。
- 书籍页面保留原来的缩放范围；无界轴或大尺寸页面可降低至 1e-7 倍，启用同一套多级显示。笔画、套索、视口使用邻近原点，网点相位保持世界锚定。
- 导出和页面缩略图：有限轴保留完整设定范围，无限轴采用实际内容范围，空内容采用初始观察范围。此次 PNG 单张限制为每轴不超过 16384 px 且总像素不超过 6400 万；更大的分段导出不在此次范围。油漆桶在无限制项目中禁用。

## 起始／终止设置与蚂蚁线修正

新建项目类型按钮共用边框、无间距；端点使用紧凑的互斥按钮组，不使用 checkbox 或系统玻璃样式。每轴起始选择 −∞／0，终止选择固定值／+∞，固定值输入单位为像素。负无穷起始允许负数固定终止；0 起始要求固定终止大于 0。输入、GPU 写入、选区、视口初始位置和输出范围共享这套轴边界。

蚂蚁线按屏幕像素的覆盖范围判断，而非仅查询片元中心所在画布像素的四个相邻值。用 dfdx／dfdy 将像素方形投影到画布轴，检测该足迹中的真实像素边沿；图块角落读取四个对角邻块，避免旋转时产生接缝。常量内部图块跳过检测。倍率低于 0.05 时使用有界的视口 mask 作显示近似，避免足迹查询随缩小无上限增长；原始选区数据不变。

补充验证：起始／终止组合、负数终止、CPU／GPU 裁切及持久化通过；内部选区线在 4 个倍率、4 个角度、4 个亚像素平移相位（64 种组合）的屏幕像素足迹检查通过。完整 GPU／模型／存储日志 351 项通过，三语条目 335 个完整。
