# ADR 0015：标尺、导航与可见内容提示

- 日期：2026-10-15
- 状态：已实施

## 输入与项目卡片

画布上的画笔、橡皮、选区、套索填充、油漆桶、组合键取色只接受 Apple Pencil。手指保留视口平移、双指缩放／旋转、双指撤销与三指重做。工具栏、面板和导航仍可用触摸操作。项目卡片显示项目用途（书籍／无限制），含当前项目卡片；类型名称使用应用语言。

## 标尺

topbar 提供应用级持久化开关。用户确认：左／右边缘对应沿画布 Y 方向的标尺，显示 Y 坐标；上／下边缘对应沿画布 X 方向，显示 X 坐标。单位暂为像素。

两轴独立计算。固定边缘实际出现在视口中，且可见线段长度不少于 96 个逻辑显示点、有空间放置外侧刻度时，在边缘外侧绘制；优先左／上，再右／下。真实边缘长度受另一轴起始和终止约束，不能把无限延长的数学直线当作画布边缘。

没有合适边缘时，标尺直线沿画布轴穿过屏幕锚点：左边缘中点右移 24 点，或上边缘中点下移 24 点。旋转后直线仍沿画布轴；仅靠近两端保留两个刻度及数值。普通边缘模式采用随倍率调整的 1／2／5 系列主刻度和五分之一小刻度。

`CanvasViewportGeometry` 用 Double 精度做坐标变换、线段裁切、中心定位和凸四边形分离轴相交判断。SwiftUI Canvas 只画显示辅助信息，不接收输入、不修改文档、不进入历史或导出。

## 导航

导航与图层面板是右侧的两个同级面板。回正按钮移至导航标题栏，保留原来“倍率不变、视口中心的内容不变”的行为。

范围复用页面有限输出范围：每端有固定坐标时使用该坐标；无限端使用实际内容框，无内容时使用初始观察框。纯色背景不扩大内容框。图像基于当前图层可视性和效果合成；显示实际视口的旋转四边形并裁切到导航图像范围。点按／拖动在世界坐标中居中，保留倍率和旋转。

导航缩略图随历史和实际内容范围更新，视口轮廓随变换更新。导航渲染完成后恢复视口渲染的工作原点和保护范围；变换通知在主线程合并，蚂蚁线动画不重复生成导航缩略图。

## 眼睛图标

在视口内具有内容图块实际 bounding box 的有效可见绘画图层，以强调色显示眼睛。父文件夹汇总其有效可见后代。隐藏状态沿用灰色，纯色图层不因常量背景而产生图块高亮，蒙版图块不作为内容范围。

先以稀疏图块索引筛选视口外接范围，再用旋转视口的真实凸四边形相交判断，避免旋转后外接矩形角落的误高亮。仅接触视口边缘、没有正面积重合的内容不高亮。
