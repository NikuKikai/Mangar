# ADR 0015：标尺、导航与可见内容提示

- 日期：2026-10-15
- 状态：已实施

## 输入与项目卡片

画布上的画笔、橡皮、选区、套索填充、油漆桶、组合键取色只接受 Apple Pencil。双指用于视口平移、缩放／旋转，双指点击撤销，三指点击重做；单指不拖动画布。工具栏、面板和导航仍可用触摸操作。项目卡片显示项目用途（书籍／无限制），含当前项目卡片；类型名称使用应用语言。

## 标尺

导航标题栏提供应用级持久化开关。左／右边缘对应沿画布 Y 方向的标尺，显示 Y 坐标；上／下边缘对应沿画布 X 方向，显示 X 坐标。单位暂为像素。

两轴独立计算。固定边缘实际出现在视口中，且可见线段长度不少于 96 个逻辑显示点、有空间放置外侧刻度时，在边缘外侧绘制；优先左／上，再右／下。真实边缘长度受另一轴起始和终止约束，不能把无限延长的数学直线当作画布边缘。

没有合适边缘时，标尺直线沿画布轴穿过屏幕锚点：左边缘中点右移 24 点，或上边缘中点下移 24 点。旋转后直线仍沿画布轴；仅靠近两端保留两个刻度及数值。普通边缘模式采用随倍率调整的 1／2／5 系列主刻度和五分之一小刻度。

`CanvasViewportGeometry` 用 Double 精度做坐标变换、线段裁切、中心定位和凸四边形分离轴相交判断。SwiftUI Canvas 只画显示辅助信息，不接收输入、不修改文档、不进入历史或导出。

## 导航

导航与图层面板是右侧的两个同级面板。回正按钮移至导航标题栏，保留原来“倍率不变、视口中心的内容不变”的行为。

范围复用页面有限输出范围：每端有固定坐标时使用该坐标；无限端使用实际内容框，无内容时使用初始观察框。纯色背景不扩大内容框。图像基于当前图层可视性和效果合成；显示实际视口的旋转四边形并裁切到导航图像范围。点按／拖动在世界坐标中居中，保留倍率和旋转。

导航缩略图随历史和实际内容范围更新，视口轮廓随变换更新。导航渲染完成后恢复视口渲染的工作原点和保护范围；变换通知在主线程合并，蚂蚁线动画不重复生成导航缩略图。

## 眼睛图标

在视口内具有内容图块实际 bounding box 的有效可见绘画图层，以强调色显示眼睛。父文件夹汇总其有效可见后代。隐藏状态沿用灰色，纯色图层不因常量背景而产生图块高亮，蒙版图块不作为内容范围。

先以稀疏图块索引筛选视口外接范围，再用旋转视口的真实凸四边形相交判断，避免旋转后外接矩形角落的误高亮。仅接触视口边缘、没有正面积重合的内容不高亮。

## 显示与缩放约束

项目类型标记放在卡片最底行右侧。标尺线、刻度和数值统一使用高亮色。导航提供 `1:1` 缩放按钮：按图像像素与屏幕物理像素 1:1 计算，Retina 屏幕结合 contentScaleFactor 换算；保持旋转和原视口中心的世界坐标。

边缘模式的标尺线延伸至视口边界，不再按画布角点截断或在视口内缩 30 点；边缘资格仍由真实画布边缘可见长度判定。边界附近的数值保持可读留白，刻度和主线不缩短。

## 2026-10-19：缩放下限与 1:1 按钮

所有项目共用 1% 的屏幕像素缩放下限，在 renderer 的 viewport zoom 入口统一约束，涵盖手势、初始适配和状态恢复。内部缩放仍以逻辑点计，按 contentScaleFactor 换算；用于缩略图和导出的局部渲染倍率不受视口下限影响。

导航将复位按钮标记改为 `1:1`，尺寸与回正按钮一致，使用共享的紧凑按钮规格，保留中心锚点与旋转；旁边独立显示当前百分比，仍以物理像素比例计算，不把操作按钮当成状态显示。

## 验证

检查覆盖双轴独立选择、短边缘和右边缘回退、旋转时的锚点、远坐标导航定位、旋转外接矩形误判、零面积接触及保持中心的缩放。GPU、模型和本地化检查入口见[开发指南](../development.md#验证)。
