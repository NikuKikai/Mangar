# ADR 0016 — 文档三维预览

状态：已采纳；记录初始书页预览方案。

展示形式的扩展见 [ADR 0017](0017-spherical-page-surface.md)；透明纸张、实际页面堆叠、纹理分辨率和保存后缓存采用 [ADR 0019](0019-transparent-page-references.md)，替代下文对应的初始设定。

## 决策

- 项目用途、页面结构、三维展示形式是不同维度。DocumentPreviewForm 根据前两者解析展示形式；本版仅 book + bookSpreads 对应书籍。未来卷轴、折页提供独立布局与几何实现，不在绘画渲染器内添加特例。
- BookPreviewLayout 将页面排列转换成实体书的可见左右面，保留补白，排除末尾添加页面用的空容器。阅读方向沿用当前书籍右至左顺序，起始侧保持现有定义。对开画稿裁至内容框后共享贴图，左右各取一半 UV；翻动纸张正反面来自相邻开面的对应页，不复制同一面。
- 当前页以不可变区块快照纳入预览，其他页按需读取磁盘索引。不开启自动保存，不改变当前页、历史或编辑视口。
- 现有每页/项目 PNG 缩略图最长边仅 320px。预览独立使用 MetalCanvasRenderer 合成最长边 1280px 的 BGRA 贴图、生成 mipmap，保留混合模式/蒙版/效果，去除编辑辅助标记。透明部分以白纸呈现。
- 贴图按源页面去重，按需串行合成，预取相邻开面，LRU 预算 64MiB；本版固定预览分辨率。退出释放缓存及临时快照。未来可按放大倍率扩展分辨率档位。
- 独立 Metal 渲染器绘制双面细分网格，顶点 shader 以圆弧积分变形实现翻页；书缝使用实际肩部曲线与解析导数生成网格及法线，弯曲程度为 0…0.4 参数；不再使用按 UV 固定变暗的书缝贴色。固定相机和世界方向光，手势旋转书本的顶点与法线，独立 1024px 深度 shadow map + 3×3 PCF 计算纸张自遮挡和翻页投影。不实现布料物理、封面装订模拟和纸张碰撞。
- 左右滑动翻页（直接跟随拖动，放开后用显示刷新同步的曲线运动完成或回弹），双指移动在有限角度内转动整体、捏合缩放；按钮翻页同样驱动纸张动画，UI 不添加淡入淡出。单个 pan 手势在第二根手指加入时转为旋转，避免单指识别器抢占旋转。纸堆按剩余/已翻页量连续调整错位与深度，明暗交替表现纸边。入口与标题统一称为「3D预览」，以文字 3D 为图标；工具栏按当前书籍右至左的阅读方向映射：左箭头下一、右箭头上一；起始侧仍只影响页面配对。翻动页与被遮挡页使用连续的纸厚分离，完成时几何精确接回静止页面，避免相邻面的深度竞争与终点跳变。预览属于查看操作，允许手指。
- 翻动页的卷曲符号由翻页方向决定：从左向右与从右向左在相同推进量下使用镜像曲面，而非沿同一变形轨迹倒放；颜色、法线和阴影共用此曲面计算。
- 书脊采用独立的封闭体积网格，顶面沿用书缝曲线，侧面、底面及上下端帽闭合，并进入颜色与阴影两条渲染路径。翻动页的额外抬升在根部衰减至零，保证装订根部不脱离书脊，避免纸张间距形成贯穿光路。
- 入口在页面一览 topbar；当前未映射展示形式的项目不显示书籍预览入口。

## 后果

保存仍只维护轻量缩略图，进入预览需要短暂合成。单页贴图质量上限固定，极度放大不会增加细节。页面数量不直接决定 GPU 常驻贴图量；页面几何仅绘制当前与翻动相关表面。书籍预览不代表印厂的装订或印刷色彩校样。
