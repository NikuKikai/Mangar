# ADR 0017：页面表面类型与球面预览

- 日期：2026-10-22
- 状态：已采纳

## 背景

无限制项目需要逐页选择普通平面或球面。球面使用当前位置周围的平面绘画内容，按径向圆弧映射显示一个半球；不把原有图块改成球面坐标，也不建立球面网格。

## 决策

### 数据与入口

- `PageSurface` 独立于 `ProjectPurpose`、`PageStructure`，保存在各页 `state.json`。普通类型不改变编辑、保存、导出、缩略图行为。
- 无限制项目中的有限、单向无限和双向无限页面均可选择球面；表面类型不再取决于边界是否无限。半径以画布像素为单位，默认 1024 px，有效范围 1…1,000,000,000 px。
- 新建项目设置初始化所有页面；新增普通卡片继承当前页面的表面设置。页面一览 topbar 打开紧凑的模式参数面板，以互斥按钮直接切换当前页类型，下方显示球面半径和画布外填充。面板通过 SwiftUI 布局锚点定位到入口按钮下方，点击外部关闭，不使用原生玻璃菜单或动画。半径在提交、失焦或关闭时提交有效输入。3D 入口在页面一览始终显示；当前页没有可用预览形式时变暗并禁用。变更通过可重放的 `setPageSurface` 命令提交，支持撤销、重做并随页面保存。
- `DocumentPreviewForm` 根据项目、页面结构和当前页表面选择预览实现。`DocumentPreviewSource` 提供与编辑器独立的不可变数据快照，供书籍和球面预览共享。

### 几何与采样

- 当前画布位置为局部极坐标原点，球半径为 R。画布源半径为 πR/2，对应球体大圆周长的四分之一，即可见半球的球面弧长。
- 正向投影为 r = R·sin(ρ/R)，其中 ρ 是画布径向距离、r 是球面预览投影距离。
- `MetalSphereRenderer` 只绘制覆盖视口的两个三角形。fragment shader 对圆盘内每个像素执行反向映射 ρ = R·asin(r/R)，取得源图像颜色；圆外不绘制。保持画布向右、向下方向，不加光影。有限边界外的源坐标在 shader 中使用页面保存的填充选项：白色、黑色或透明（默认）。填充仅在球面圆盘内生效，不修改画布或导出，也不覆盖边界内的内容。边界同样转换为相对贴图原点的局部坐标。
- 编辑器用原有内容框 shader 的圆形分支，绘制以视口中心对应画布坐标为圆心、半径 πR/2 的范围线。颜色和屏幕线宽与书籍内容框相同；导出与缩略图不包含该辅助线。

### 交互与缓存

- 进入预览时中心取当前编辑视口的画布中心，并限制到页面边界内。手指平移改变此中心；X、Y 轴独立按已有起始、终止边界限制，到边后不能继续越过，无限端不限制。捏合调整显示大小；回正按钮重置为进入时中心和初始显示大小。退出不改变绘画视口或文档数据。
- 只合成源圆周围的有界区域，复用已有图层、效果、mask、稀疏图块和 LOD 路径。每张区域贴图最长边 1536，包含 mipmap。
- 贴图区域半边长为源半径的 1.5 倍；中心移动但可见源圆仍在贴图内时只更新 shader 参数。需要更新时只排一个任务，以最新位置合成并整体替换贴图和坐标范围。
- 合成器沿用已有图块驻留预算，区域更新后清理旧位置的驻留图块。球面预览不累积各个位置的贴图。
- 世界中心使用 Double，传给 GPU 的中心和采样位置均相对当前区域原点，避免大正负坐标下的浮点精度损失。

## 后果与范围

球面只是页面的观察方式，绘画仍是平面稀疏数据，PNG 导出仍为平面内容。当前为以局部极坐标定义的半球视图，不是经纬度展开、全局纹理接缝或可闭合的完整球面模型。进入和移动至新区域需要合成，极度放大受区域贴图分辨率限制。球面半径和模式持久化，预览临时中心和缩放不持久化。
