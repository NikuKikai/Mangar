# ADR 0018：编辑视图中的对页参考

- 日期：2026-10-22
- 状态：已采纳

## 决策

- 仅对书籍项目的单页启用。从 `PageContainer` 的真实排列中查找同一对开的另一单页；留空位置、追加位置和整张对开画布不提供参考图。
- 读取对页元数据与已保存的轻量缩略图，不为显示对页解码全部绘画图块。缺少缩略图时沿用现有按需生成路径。
- 两页内容框的相邻边相接，内容框上沿对齐。用 DPI 比例换算像素尺寸，保留实际大小；两个画布的余量因此在书缝处重叠。
- 对页纹理使用独立 Metal fragment shader，在编辑视图绘制完成后叠加。它不受当前页面边界或选区裁切，随同一画布变换缩放、旋转、平移；重叠处对页在上。
- 叠加仅存在于视口，不进入页面内容、撤销历史、保存缩略图、PNG 导出或 3D 预览。每次仅保留当前对页的一张纹理，切换页面时检查所属页面 ID，避免旧图显示到新页。
- 导航栏使用可复用的 `ScrubbableToggleButton`：点击切换；按住上下移动调整 0…100% 不透明度，上移增大，下移减小。拖动时开启显示，释放后不额外切换；取消时恢复按下前状态。百分比只在调节时临时显示，无动画。
- 开关与不透明度属于应用级视图偏好，默认开启、100%，与页面绘画数据分开持久化。

## 后果

参考图沿用最长边 320 px 的缩略图，放大时不会具备绘画原图的细节；它用于对照位置与构图，不可编辑。显示开关不改变描绘、取色或选区工具的目标页面。

## 数值水位显示

`ControlValueLevel` 为上下拖动型控件提供统一的底部向上填充和单显示像素水位线。对页透明度按钮和 `VerticalDragProperty` 的数字属性（包括图层透明度）共用此实现；数字按自身范围归一化，枚举选择不显示水位。文字和图标在填充上方，按下反馈仍独立叠加。关闭开关时保留灰色水位，禁用时减弱显示；0 和 100% 不绘制额外边线。所有更新禁用 CALayer 隐式动画，不增加 UIView 或触摸区域。
