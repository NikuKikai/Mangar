# ADR 0019：透明对页、反面参考与 3D 书页

- 日期：2026-10-22
- 状态：已采纳
- 取代 ADR 0018 中使用 320 px 缩略图作为编辑参考的决策。

## 决策

- 320 px 缩略图继续用于项目和页面卡片。进入编辑页时，复用 `DocumentPreviewSource` 的独立 GPU 合成器，直接渲染最长边最多 4096 px 的对页和反面纹理，不经过 PNG / UIImage，不包含编辑器辅助显示。常规页面按原像素呈现，超大页面按上限缩小；生成 mipmap。
- 合成输出使用透明清屏，保留图层合成后的预乘 alpha。对页沿用完整画布、DPI 对齐与上层叠放逻辑。反面使用内容框区域，水平镜像后置于当前页内容下方，仅从当前内容的透明处透出。粉紫色显示模式保持反面原 alpha。
- 反面以物理纸张为单位计算：第 i 个对开的左页对应 i+1 的右页；右页对应 i-1 的左页。整张对开画布可以分别对应两个不同来源的反面。没有对应页时视为空白透明区域。
- 参考加载以页面及配对关系为身份，可取消，切换页时立即清理旧引用；离开画布视图释放编辑参考。源渲染缓存采用有预算的 LRU；编辑器仅持有当前需要的参考，不进入绘画内容、导出、取色或保存缩略图。
- 图层列表下方一行提供反面显示、粉紫色着色、创建选区。创建选区取完整反面 alpha，不限于正面露出的部分；按当前画布像素生成 R8 分块，保留连续值。命令携带 LZFSE 压缩覆盖数据以保证撤销重做不受反面后续修改影响；空块省略，全 255 块只存标记。生成过程以 16 块为一批，避免整页 R8 中间缓冲。
- 3D 纸张继续使用一张可变形网格。着色器分别按正反面的 UV 采样，以朝向面的颜色优先，与另一面按 `A + B × (1 − A.alpha)` 合成；两面都透明处剔除。这样可以显示两面不一致的轮廓，无双网格深度冲突。透明阴影使用有序覆盖和 PCF；书脊仍为实体。
- 底部纸张堆叠使用实际页面及反面，不使用白色矩形占位纸张。翻页前后按同一连续深度与偏移公式摆放，避免释放后的轮廓跳变。附近页面使用较高分辨率，远处堆叠使用低分辨率；仅保留附近纸张。

## 保存后的派生缓存

- 页面权威数据保存成功后，排队生成完整画布与内容框的透明合成缓存（最长边 4096 px）；两者区域相同则共用一次渲染结果。使用独立合成器，任务可取消，不访问后续尚未保存的编辑数据。
- 缓存放在各页的 `previews/canvas.mgpreview`、`content.mgpreview`。BGRA8 预乘像素使用 LZFSE 无损压缩，不经过 PNG 的 alpha 转换；文件包含格式版本、页面状态 SHA-256、区域、尺寸与像素 SHA-256，头部和压缩像素在同一个文件中原子发布。
- 页面状态文件已包含元数据与不可变图块文件引用，因此其 SHA-256 可作为修订依据，不修改工程格式。迟到的旧任务发布前检查修订；读取时再次按当前状态、区域和校验和验证。缓存失效、损坏或缺失只导致按需重渲染，不影响工程读取。
- GPU 合成和读回在保存返回后的任务中执行；压缩、校验及写文件在 utility 后台任务执行。生成失败不改变已成功的保存结果；不在每个笔画后生成整页缓存。
- 编辑对页、反面和书页 3D 预览优先读缓存；当前未保存页面的快照始终优先。远处纸张只保留所需 mip 分辨率，避免因磁盘缓存较高清晰度而占用完整 GPU 纹理。球面视口的动态区域仍按需合成。
- 320 px 卡片缩略图继续独立维护。旧页面不批量迁移，保存时生成新缓存。

## 画布手势

编辑画布只用双指进行平移、缩放和旋转；单指按下、移动，以及双指操作释放一指后均不改变视口。双指/三指点击撤销重做与 Pencil 工具路径保持独立。
