# 功能说明

## 项目与页面

启动后进入项目管理界面，以卡片展示工程。工程以目录保存，每页有独立文件，由项目清单关联；单页与多页使用相同结构。工程位于应用的 Documents 目录，可通过「文件」访问和导入。

- **书籍项目**：以 mm 和 DPI 定义内容尺寸及余量，提供尺寸预设、内容框和出血框。页面按对开排列，可选择左页或右页起始，支持单页和对开画布的合并／拆分。
- **无限制项目**：使用普通多页卡片。X、Y 轴分别设置起始为 −∞ 或 0，终止为固定坐标或 +∞；有限和无界区域共用稀疏图块架构。

新页面包含锁定的白色纯色背景层。隐藏背景层可显示透明格子。

## 绘画与输入

提供铅笔、G 笔、持续出墨针管笔、二值笔、平头油画笔、水彩洗染笔及橡皮擦。支持透明色与应用级颜色预设。

- 笔刷参数和当前颜色独立于项目保存，每支笔记忆各自的设置。
- 大小、流量和不透明度支持压力、速度、倾斜等输入的可选平滑响应曲线；全局压感曲线位于应用菜单。
- 铅笔可通过倾斜改变笔尖大小。G 笔与针管笔通过宽度表现出墨量；针管笔快速移动变细，停笔时持续扩墨。
- 二值笔控制笔尖边缘的抗锯齿方式，不限制颜色。
- 笔尖图片在第一级参数面板中设置，支持透明度或灰度通道、宽高比、偏角、方向和顺序／随机选择。每支笔最多 16 张素材，单张最长边 1024 px。
- 油彩和水彩支持当前图层的笔前拾色、光谱颜料混合及颜料耗尽；水彩另有含水量、颗粒和边缘积色。其行为是确定性的绘画近似，不包含厚度、笔后流体扩散或真实纸张含水量模拟，也不跨图层合成取样。

画布上的绘画、选区和取色工具仅接受 Apple Pencil。双指可平移、缩放和旋转视口；双指点击撤销，三指点击重做。手指单独移动不拖动画布。

左下角组合键按钮按住生效。按住 Option 并移动笔可连续取色；按住 Command＋Option 拖动笔可调整笔刷大小。

## 图层与选区

图层支持文件夹、多选、主编辑对象、可见性、锁定、混合模式和不透明度。通过拖拽 handle 调整顺序与层级；属性标签可上下拖动调节。

- **蒙版**：使用单通道 R8 数据，新建为全白。选择蒙版缩略图后，绘画颜色转换为灰度值写入蒙版。
- **网点与曲线**：图层可同时应用网点和调整曲线；两者的参数区共用位置，互斥展开。
- **选区**：矩形与套索保留连续覆盖率，支持 Shift 加算、Option 减算及两者同时按下时的交集。提供反转、清除和连续值着色观察。
- **填充**：支持套索填充。油漆桶可调容差和闭合间隙，参考当前编辑目标；无限制项目中禁用油漆桶。
- **清空**：作用于当前图层或蒙版，有选区时按选区覆盖率处理。

无限制项目的普通平面模式支持图层视差。各层独立启停，z 为 −99～99 的整数；标签显示 `z+数值`、`z-数值` 或 `z=0`。关闭时自身有效 z 为 0，并保留设定值。文件夹的有效 z 与子层相加，视差不改变大小或合成顺序。工程边界是最终画面窗口，偏移后的图层仍可在窗口内绘画，实际数据可以位于窗口外的局部坐标中。球面模式不启用图层视差。

## 导航与预览

右侧导航提供定位、回正、1:1 缩放和标尺开关。回正与 1:1 缩放保留视口中心对应的内容位置；1:1 表示图像像素与屏幕物理像素一一对应。最小视口缩放率为 1%。

书籍单页可在画布边缘显示对应对页，按内容框和 DPI 对齐；导航栏按钮可切换显示并上下拖动调节透明度。图层列表下方提供反面显示、粉紫色着色和从完整反面 alpha 创建选区。

页面一览提供 **3D预览** 入口；不支持的形式显示为禁用状态。

- **书页**：支持弯曲书缝、翻页动画、双指旋转和缩放，以及透明轮廓、反面内容透出与对应阴影。
- **球面**：普通画布通过着色器映射为半球显示，拖动改变观察位置；可设置半径以及画布外区域的白色、黑色或透明填充。

编辑参考图最长边为 4096 px，卡片缩略图最长边为 320 px。参考和 3D 纹理有分辨率上限，放大后不会补充原图细节。

## 保存与导出

绘画图块采用 LZFSE 无损压缩，按修改增量保存，通过原子状态文件关联不可变图块。保存页面后生成可重建的透明合成缓存，供页面参考和书页预览复用；缓存缺失、过期或损坏时重新渲染。

提供显式保存；页面切换等需要保存的操作会提交当前页面。未完成笔画的预览不作为正式数据保存。撤销历史保留在内存中，重新打开工程后从新的检查点开始。

导出支持 PNG，书籍项目默认裁切至内容框。有限轴保留设定范围，无限轴取内容范围。单张输出限制为每轴 16384 px、总计 6400 万像素。透明格子、选区线、辅助框及临时着色不进入导出；视差使用基准视角。PSD 导出、分段超大图导出及笔刷库管理界面尚未提供。

## 语言

支持简体中文、日文和英文。可在编辑菜单或项目管理菜单的「应用设定」中选择语言或跟随系统。语言和应用工具设置持久化保存，不改写已有项目、页面或图层名称。
